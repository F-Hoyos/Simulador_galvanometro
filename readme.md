## 1. Descargar el repositorio desde github.

## 2. Requisitos

- Tener Python instalado.
- Instalar la librería Matplotlib para generar las gráficas.

Para instalar Matplotlib, ejecutar en la terminal:

```bash
python -m pip install matplotlib
```

## 3. Ejecución del programa

1. Abrir la carpeta del proyecto.
2. Abrir una terminal en esa ubicación.
3. Ejecutar el siguiente comando:

```bash
python galvanometro.py
```

## 4. Resultados

Al ejecutar el programa se mostrarán los parámetros del galvanómetro y los resultados de la simulación.

También se abrirá una gráfica que compara la solución numérica (RK4) con la solución analítica.

La gráfica se guarda automáticamente como:

`grafica_galvanometro.png`

## 5. Consideraciones

- El método RK4 está implementado directamente en el código.
- No se utilizan librerías que resuelvan automáticamente ecuaciones diferenciales.
- Los parámetros y las condiciones iniciales pueden modificarse en el archivo `galvanometro.py`.
